# NOTE ON WHAT THIS FILE IS ACTUALLY FOR.
# The password policy already requires 12 characters, which by itself blocks
# almost every entry in a typical "top 1000 passwords" list — `password`,
# `123456`, `qwerty` are all too short to reach this check. So the entries that
# do real work here are the LONG-but-common ones: padded numbers, keyboard
# walks, repeated words, and common phrases. This list is weighted accordingly.
#
# Swapping in a bigger list (SecLists rockyou top-10k, filtered to >=12 chars)
# needs no code change — point COMMON_PASSWORDS_PATH at it.
